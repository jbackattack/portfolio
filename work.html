AI test agents, from an automation prototype to live agents

My team built three live QA agents on the infrastructure team's shared agent framework: a test case analyzer, a test case creator, and a mobile data lookup that queries BigQuery directly instead of waiting on dashboards. The analyzer reviews existing test repos against best practices, and the creator writes new tests to the same standard.

They followed an automation prototype I designed, where AI drafts mobile tests and QA acts as the risk assessor and approval gate. It included a 13-file agent framework and a Jira epic with eight to nine child stories. It was first written up as a GitHub extension, but we decided to build on the infrastructure team's live agent setup instead, so the prototype never went to production.

Impact
On its first run, the analyzer found security problems in existing tests, including passwords stored in insecure places
Role
Designed the automation prototype; my team built the live agents
Stack
Appium, Java, TestNG, Bitrise, LambdaTest, GitHub Copilot
Status
Three agents built and deployed; the prototype did not ship

One element-ID standard for React Native

Mobile tests break when elements can't be found. I defined one rule for the React Native app: every element gets the accessible flag, a testID, and an accessibility ID. Tests locate elements with Appium's accessibility ID strategy. The same locator then works on iOS and Android.

A new testing model for the whole tech organization

As the company's needs changed, I designed a different way to test across engineering. I split QA into two teams: a web team for ad revenue and content tools, and a mobile team focused on automation. Product engineers took on their own manual testing, using group testing sessions in place of team demos and the tools QA had used.

The shift was from quality assurance to quality assistance: QA sets up the tools and practices so teams can test well themselves.

Role
Designed the strategy and the team structure

Replacing an outside testing vendor

I reviewed our outside testing contract every year against what it delivered. Usage was low, and what it found was mostly low-priority bugs. I ended the contract.

To replace it, I moved both automated and manual device testing to a new vendor, so one platform covered both at a fraction of the price.

Impact
Over $130,000 saved with little loss in test coverage
Role
Fully evaluated the options, made the decision, and led the transition

Cutting wasted builds and heading off a vendor price increase

We had a monthly allotment of test builds and runs, and usage kept eating into it. I worked with engineering to trace why, and we found that more builds were being created per test than necessary. That inflated our usage against the budget without testing anything new.

Once the extra builds were removed, we were able to pay for fewer builds each month, and our CI subscription no longer had to grow to cover them.

Impact
Stopped a potential annual subscription increase from a third-party vendor
Role
Found the cause with engineering; kept the subscription from growing

Pack 55 wreath sale app

An ordering and inventory app for a scout pack's wreath fundraiser, including door-to-door sales status. I was the whole team: I came up with it, decided what it should do, and directed the build with Claude. Umpire rules study quiz

A practice quiz for high school baseball and softball umpire recertification. I umpired years ago, I'm getting recertified, and I couldn't find a good quiz to study with, so I built one with Claude.

You pick a sport and a length, and each test is a random draw from a larger question bank that favors questions you haven't seen or missed last time. It shows right or wrong immediately and tracks progress by sport, with a review list of misses. Questions live in a Google Sheet, so I can add or fix them without touching code, and the quiz keeps a saved copy so it works offline.

It's for my own study, so it isn't public.

Role
The whole team: product, engineering, and QA
Stack
HTML, JavaScript, Google Sheets
