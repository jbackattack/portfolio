Spark: AI-assisted mobile test generation

A 13-file agent framework where AI drafts mobile tests and QA acts as the risk assessor and approval gate. It uses a single delivery lane, test generation limits that follow risk, and three ways to trigger a run.

I designed the whole framework, structured the Jira epic (eight to nine child stories), and handed it to an iOS engineering manager to build.

Role
Designed the framework and the delivery plan
Stack
Appium, Java, TestNG, Bitrise, LambdaTest, GitHub Copilot
Status
Designed and handed off for implementation

One element-ID standard for React Native

Mobile tests break when elements can't be found. I defined one rule for the React Native app: every element gets accessible, a testID, and an accessibility ID, and tests locate elements with Appium's accessibility ID strategy. The same locator then works on iOS and Android.

Role
Defined the standard
Stack
React Native, Appium, Java

Nightly smoke suites and a device benchmark

I changed the team's QA strategy from manual card testing to nightly smoke suites plus AI-generated test creation. I also planned a benchmark pilot to compare simulators and emulators against LambdaTest real devices for the nightly runs.

Onboarding for AI testing agents
